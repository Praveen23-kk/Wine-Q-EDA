## 📌 Project Overview
This repository contains an in-depth **Exploratory Data Analysis (EDA)** of the **Wine Quality Dataset**. The main objective of this project is to explore the physiochemical properties of wine and understand how different chemical features (like acidity, sugar content, pH, and alcohol) influence the overall quality rating of the wine. 

By utilizing data visualization and statistical summaries, this project uncovers key insights that can be useful for winemakers and data enthusiasts alike.

## 📊 Dataset Information
The dataset used in this analysis is the classic **Wine Quality Dataset** (commonly found on the UCI Machine Learning Repository or Kaggle). It consists of physicochemical tests of wine samples and their corresponding quality ratings (scored from 0 to 10).

**Key Features Include:**
*   `Fixed acidity` 
*   `Volatile acidity`
*   `Citric acid`
*   `Residual sugar`
*   `Chlorides`
*   `Free sulfur dioxide`
*   `Total sulfur dioxide`
*   `Density`
*   `pH`
*   `Sulphates`
*   `Alcohol`
*   **Target Variable:** `Quality` (Score between 0 and 10)

## 🎯 Objectives
*   Perform data cleaning and handle any missing or duplicate values.
*   Understand the distribution of different physicochemical properties.
*   Identify correlations between features using heatmaps and scatter plots.
*   Determine which features have the strongest impact on wine quality.
*   Detect and handle outliers within the dataset.

## 🛠️ Tools & Libraries Used
The following Python libraries were utilized for this analysis:
*   **Pandas:** Data manipulation and analysis
*   **NumPy:** Numerical computing
*   **Matplotlib:** Basic data visualization
*   **Seaborn:** Statistical data visualization and aesthetically pleasing graphs
